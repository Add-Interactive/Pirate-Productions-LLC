## 🎸 About Pirate Productions

**Pirate Productions LLC** is a full-service, Live Nation-scale live event staffing company operating out of **Nashville, Tennessee**. We provide battle-tested, certified production crews for stadium rock tours, multi-day music festivals, arena concerts, and high-impact corporate keynotes across North America.

From high steel climbers hanging 95-ton stadium trusses at **Nissan Stadium** to FOH mix engineers and heavy machine operators at **Bridgestone Arena**, Pirate Productions delivers 100% OSHA and ETCP-certified trades to bring world-class live events to life.

## 🚀 Quick Start Guide

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.0 or higher)
- [npm](https://www.npmjs.com/) (v9.0 or higher)

### Installation

1. **Clone the Repository**
   ```bash
   git clone https://github.com/Add-Interactive/Pirate-Productions-LLC.git
   cd Pirate-Productions-LLC
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Start Development Server**
   ```bash
   npm run dev
   ```
   Open your browser at `http://localhost:5173/`.

4. **Build for Production**
   ```bash
   npm run build
   ```
